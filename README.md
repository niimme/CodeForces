# Codeforces Interactive Learning & Practice Platform 🚀

A modern, high-performance web platform for competitive programming and algorithm practice based on top-solved Codeforces problems.

## ✨ Features

- **🎮 Gamified Learning Roadmap**:
  - Interactive problem nodes categorized by topic (Math, Strings, Dynamic Programming, Graphs, etc.)
  - Progress tracking, experience badges, and difficulty ratings
  - Seamless navigation to hands-on problem workspaces

- **💻 Multi-Language Code Editor**:
  - Pixel-perfect typography with native **Menlo / Monaco / JetBrains Mono** font stack
  - High-fidelity syntax highlighting matching macOS developer toolkits
  - **Interactive Breakpoints**: Click directly on the line gutter to toggle breakpoints (with orange breakpoint markers), or manage them via the editor toolbar
  - Code folding (`▾`) on block structures
  - Active line highlighting
  - Multi-language support: **C++ (C++20 / clang++)**, **JavaScript (Node.js)**, and **Python 3**

- **⚡ Split-Screen Problem Workspace**:
  - Minimalist 1px sizable dividers for flexible window resizing
  - Top instructions toolbar (`📄 Instructions`, `📋 Log`, `💡 Hints`, `Dashboard →`)
  - Integrated Test Runner Console with instant evaluation and diagnostic logs
  - Celebration animations upon passing all test cases

## 🛠️ Tech Stack

- **Framework**: Next.js 14+ (App Router)
- **Language**: TypeScript & React
- **Styling**: Vanilla CSS Design System with CSS Variables
- **Math Rendering**: KaTeX
- **Icons & Effects**: Canvas Confetti

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or newer)
- npm or pnpm

### Installation

```bash
# Clone repository
git clone https://github.com/niimme/CodeForces.git
cd CodeForces

# Install dependencies
npm install

# Run the local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
